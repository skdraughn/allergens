# Ingredient Intelligence v2

Runtime manifest for the strengthened Ingredient Intelligence layer.

Changes from v1:

- Broader reviewed fish, shellfish, sandwich, dessert, and raw-bar coverage.
- Field-aware dish-shape rules for common menu forms that imply allergen concerns.
- Rule provenance using Wikidata, Open Food Facts, manual-approved, or Codex-reviewed sources.

Runtime refreshes must read this manifest locally and must not call Wikidata, Open Food Facts, or a model live. Codex/model review is an offline candidate-generation and approval workflow only.
